## 1. Executive Summary & The 57-Repo Fusion

The `.agents` infrastructure is an agentic engineering engine designed to convert probabilistic Large Language Models (LLMs) into reliable, deterministic software delivery agents. 

Rather than relying on ad-hoc prompts or bloated external frameworks, `.agents` consolidates structural patterns from 57 specialized developer-tooling and agentic repositories into a cohesive, zero-daemon framework:

### Core Architecture Highlights
- **Four Anchored Pillars**: Zero mandatory pip dependencies. Pure Python stdlib (`ast`, `re`, `sqlite3`, `hashlib`, `urllib`), Cargo Rust (`rtk`, `ast-grep`), local Ollama embeddings (`nomic-embed-text`), and Bun runtime.
- **Dual-Level GraphRAG**: Pure-Python Louvain Modularity community detection combined with local vector embeddings and SQLite FTS5 lexical BM25 matching.
- **Master BIOS Router**: Dynamic Just-In-Time (JIT) skill dispatch preventing prompt pollution and "Lost in the Middle" attention degradation.
- **Crash-Proof State Machine**: Formal state tracking separating static session context (`context.json`) from active atomic execution state (`execution_state.json`).
- **Iron Evidence Law**: Exit Code 0 is required but insufficient on its own; positive proof of verified state change and assertion telemetry is required for task completion.
