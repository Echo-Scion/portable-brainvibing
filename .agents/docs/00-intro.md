## 1. Executive Summary & Architectural Synthesis

The `.agents` infrastructure is an agentic engineering engine designed to convert probabilistic Large Language Models (LLMs) into reliable, deterministic software delivery agents. 

Rather than relying on ad-hoc prompts or bloated external frameworks, `.agents` consolidates structural patterns across developer-tooling, formal verification, and cognitive memory into a cohesive, zero-daemon framework:

### Core Architecture Highlights
- **Four Anchored Pillars**: Zero mandatory pip dependencies. Pure Python stdlib (`ast`, `re`, `sqlite3`, `hashlib`, `urllib`), Cargo Rust (`rtk`, `ast-grep`), local Ollama embeddings (`nomic-embed-text`), and Bun runtime.
- **Dual-Level GraphRAG & Observational Memory**: Pure-Python Louvain Modularity community detection combined with local vector embeddings, SQLite FTS5 BM25 matching, a 3-tier epistemic compression funnel (`[O1]` anchor IDs, generational rollover), and `superseded_by` anti-flashback filtering.
- **Zero-Escape Bento Task Slicer**: Topological task sequencing ($T_0 \to T_5$), bottom-up same-file ordering, live AST anchor recalibration, disk indentation alignment, and a post-condition disk mutation gate (`orion.py bento`).
- **Master BIOS Router**: Dynamic Just-In-Time (JIT) skill dispatch via `AGENTS.md` preventing prompt pollution and "Lost in the Middle" attention degradation.
- **Cache-Aware Crash-Proof State Machine**: Formal state tracking separating static session context (`context.json` with a 5-minute SHA-256 prompt-cache preservation gate) from active atomic execution state (`execution_state.json`).
- **Universal Dynamic Context Packer & Digestpack**: Multi-stack monorepo discovery, PageRank graph topology clustering, 10-bundle ceiling, 4-turn interactive audit playbooks, and adversarial forensic hardening.
- **Habit Observation & Barrier Escalation**: 5-status observation ledger (`OBSERVATIONS.md`), cold archival (`OBSERVATIONS.archive.md`), operator habit mining, and automatic 2nd-violation Tier-0 barrier escalation.
- **Iron Evidence Law**: Exit Code 0 is required but insufficient on its own; positive proof of verified state change and assertion telemetry is required for task completion.
