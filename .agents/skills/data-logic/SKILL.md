## Architectural Invariants (Negative Constraints)
- **FORBIDDEN (In-Place Mutation)**: Never mutate state objects directly (e.g., `state.field = value`). All updates MUST produce a fresh instance via `copyWith`, immutability records, or pure reducers.
- **FORBIDDEN (Boundary Bleed)**: Never import UI/Presentation layers (widgets, controllers, HTML elements) into domain models or entities.
- **FORBIDDEN (Untyped Data)**: Never use `dynamic`, `any`, or raw untyped dictionaries in production domain models. Enforce strict schemas (Zod, Freezed, Pydantic).
- **FORBIDDEN (Over-Subscription)**: Never subscribe to broad root state objects in UI widgets. Enforce granular, field-level reactive selectors to eliminate redundant re-renders.


## Universal Workflow Patterns
1. **Selective Watch Rule**: Subscribe to specific fields to prevent unnecessary UI rebuilds.
2. **Async State Management**: Use async state containers for async mutations, read-only providers for one-off fetches.
3. **Loop Prevention**: Handle futures/streams with explicit state matchers (loading/error/data).

## Troubleshooting (Universal)
- **Model methods not generated**: Missing code generation setup or part directives.
- **UI not updating on state change**: Using one-shot read instead of reactive watch.
- **Duplicate state containers**: Multiple providers/stores with same responsibility.
