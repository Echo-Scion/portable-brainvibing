## 2. Problem Statement & Market Gap

1. **Fragmentation of Brain & Muscle**: Most trading bots have hardcoded heuristic rules with no architectural memory, while most LLM coding agents lack persistent local [[knowledge]] graphs and crash during complex multi-step execution.
2. **Environment & Hardware Brittleness**: Scripts that work on desktop fail silently on laptops or different OS environments due to IPv6 DNS traps, encoding mismatches, and unhandled hardware constraints.
3. **Split-Brain Memory Loss**: Agents repeatedly re-learn the same lessons because episodic memory, learnings, and working context are siloed and unindexed.

---

## 3. The Unfair Advantage

- **Decoupled Architecture**: High-speed trading pipeline (`scionlog/src/engine/pipeline.py`) runs independently in Python with SQLite WAL mode, while Orion provides JIT [[knowledge]] retrieval, pre-flight diagnostics, and token-efficient rule compilation.
- **Dual-Stack Local Intelligence**: Proactive hardware sensing auto-scales from lean SQLite/BM25 on 8GB RAM laptops up to high-capacity local Ollama Qwen models with dense graph triplets on workstations.
- **Darwinian Self-Evolution**: Closed trades feedback parameter calibrations into `lessons.py` and `hyperopt.py`, while agent mistakes auto-append to `LEARNINGS.md` to mutate operational rules.
