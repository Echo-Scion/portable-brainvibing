## [0.0.6] - 2026-11-05

### Added
- **Feature Discovery & Requirements Scoping**: Socratic requirements elicitation and structured design trade-off scoping skill (`feature-discovery`).
- **GraphRAG & HippoRAG Retrieval**: Pure-Python HippoRAG Personalized PageRank graph traversal, multi-hop spreading activation, progressive lazy dense vector embedding, weighted BM25 search, and unified workspace hydration (`orion brain hydrate --all`).
- **Google Stitch & Design Specification**: Full compliance for DESIGN.md schema, composite scale typography, component maps, greenfield project intake, and single-archetype catalog flattening.
- **Zero-Trust Command Guard**: Intercepts agent shell actions before execution (blocks slopsquatting package hallucinations, remote pipes, destructive directory wipes; advises on hermetic lockfiles).
- **Architecture Governance & Decision Ledger**: Native decision ledger (`orion decisions`) with persistent audit logging, zero-stall execution tracking, and active routing injection in pre-agent wakeups.
- **Test Quality & Verification Hardening**: Test pollution detector and bisection engine (`orion polluter`), deterministic condition-based async wait patterns, defense-in-depth redundant validation, 5-round bounded worker auto-fix loop, 3-option Git worktree finalization, and dynamic PoC exploit validation gates.
- **Autonomous Learning & Intent Routing**: Direct 1-hop reference JIT routing with bilingual normalizer, protected <!-- LEARNED --> blocks, and negative memory barriers against rejected intent fingerprints.

### Changed
- **BIOS Governance & Working-Tree Normalization**: Codified Dual-Loop Git Strategy balancing granular development micro-commits with clean trunk release discipline, standardized pragmatic native-IDE-first editing with programmatic scratch power-tools, normalized 3,026 files to LF line endings on disk to guarantee cross-platform exact string editing, scoped state machine transitions to headless/daemon modes, pruned cross-rule duplications, enforced JIT deduplication, and eliminated foundation backup sprawl across spokes.
- **Skill & Protocol Consolidation**: Merged token budgeting and Lessword protocol under `cost-optimizer`, realigned accessibility palette boundaries, and de-branded UI/UX skill canons and design templates into sovereign first-principles terminology.
- **Quality Gates & Graph Optimization**: Enforced real contract behaviors over synthetic mocks, locked test evaluators against unauthorized modification (`HARNESS-JDG-01`), scaled skill lifecycles by empirical success/failure ratios, and optimized graph clusters by pruning multi-valued relation collisions and trivial Louvain micro-islands.
